fetch函数：

fetch： 语法： fetch(url,options) 发起请求，返回promise对象 .then(res =>{}) 链式传递数据 .then(...) .catch(error =>{}) 任何一步出错都跳转到这里

例1用于获取文本： fetch('./test_text.txt') .then(response => { console.log(response.status); // HTTP状态码 console.log(response.ok); // 是否成功（200-299） // 将响应体转换为文本 return response.text(); }) .then(text => { // 第二个then：处理转换后的文本数据 console.log('获取到的文本：', text); document.getElementById('content').textContent = text; }) .catch(error => { console.error('请求失败：', error); });

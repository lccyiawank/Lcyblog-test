ffmpeg

安装方法：参考Windows 安装 FFmpeg 新手教程（附环境变量配置）在ffmpeg官网找到下载界面下载上个月的稳定版本。找到对应系统的四个版本（例如win64有gpl、lgpl以及两个shared版本），其中shared版本是给开放者的，lgpl版本有更宽松的知识协议。

系统变量：在系统变量中配置解压后文件的bin路径即可，注意系统变量配置需要关闭全部页面才可成功。

powershell：如果你不想用cmd，可以用powershell

确认安装：win+R打开cmd或powershell，输入ffmpeg -version确认是否安装成功

使用方法：

  • 查看信息：ffprobe "input.mp4"
  • 放缩：ffmpeg -i "input.mp4" -vf "scale=1920:1080" "output.mp4"，其中input.mp4指向输入文件的路径，output是输出文件的地址、格式和名称；如果想要等比例放缩，那么把sclae中的任意一个参数写成-1就好。
  • 下载m3u8：ffmpeg -i "xxx.m3u8" "output.mp4"
    m3u8是流媒体结构，由一个m3u8头文件和多个fs视频文件组成，其中m3u8文件包含了fs文件的播放顺序。m3u8文件的工作原理如下：
    // 1. 先下载播放列表
fetch('video.m3u8') → 获取文本文件（几KB）

// 2. 解析列表，获取所有片段地址
const segments = ['segment1.ts', 'segment2.ts', 'segment3.ts']

// 3. 依次下载片段
for (let seg of segments) {
    fetch(seg) → 下载视频片段（每个几MB）
    // 边下载边播放
}

// 4. 所有片段拼接成完整视频

    前面说了，图片也可以。例如：

    @echo off
chcp 65001 >nul
echo 开始下载图片...

curl -e "请求头网站" ^
     -A "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36" ^
     -o "output.jpg" ^
     "图片链接"

if %errorlevel% equ 0 (
    echo 下载成功！文件保存为：output.jpg
) else (
    echo 下载失败，错误代码：%errorlevel%
)

pause

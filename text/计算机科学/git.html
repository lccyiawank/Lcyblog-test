git

    git是一个用于各种各样开发的妙妙工具

  • git下载：对于windows平台，在官网用powershell的快捷下载。
  • 初始配置： git config --global user.email "你的邮箱@example.com" git config --global user.name "你的名字"
  • 关联github pages：
    cd /../project
    // 路径

    git init
    // 初始化

    在对应仓库的code获取.git的地址
    git remote add origin https://github.com/用户名/仓库名.git
    // 关联远程仓库

    git remote -v
    // 检查是否关联
    // 应该显示类似：
    // origin https://github.com/用户名/仓库名.git (fetch)
    // origin https://github.com/用户名/仓库名.git (push)

    git fetch origin
    // 拉取仓库

    git branch
    // 查看分支

    git branch -M main
    // 如果本地分支叫做master，那么重命名本地分支

    git push -u origin master:main
    // 或者把本地的master推送到main

    git checkout -b main origin/main
    git merge master
    git branch -d master
    // 或者在本地创建main且追踪远程仓库并合并master

    git add .
    // 单独一个点指的是所有文件，或者你也可以add某个文件

    git commit -m "合并初始化文件"
    // 更改说明

    git push origin main
    // 推送到github

在css中设置.avatar-wrapper img的意义是选择所有class="avatar-wrapper"的元素中的img元素并应用。当然还有.black-mask:hover（当鼠标悬停在这个class的div上时会发生...）

border-radius: 50%是制作圆形图片的主要方式，让这个元素的边框圆角的弧度，达到它自身宽度和高度的一半。为了设置为正圆，还要有width:2rem和height:2rem，2rem是相对于根元素html字体大小的单位，一般默认字体是16px，2rem是32px。

现代网站支持vue等方式实现动态html网站（SPA），但是这里还在施工中，所以你会见到许多bug。

构造SPA的方式有一，引入vue；二，全部改成SPA。区别在于，前者是在html的基础上增强一些动态功能，后者的html只是一个壳子，全部由JS渲染。

引入Vue的方法是在head头里添加一行（F12，参见本页面）；完全构造成SPA的方法是
//bash
# 创建新项目，取名 vue-spa-for-html
vue create vue-spa-for-html
# 进入项目目录
cd vue-spa-for-html
npm run build

引入Vue的好处在于，Vue是一个配置好的工具，方便合作使用。否则你自己写js代码也是一样的。用JS获取该元素，在点击时触发加一的函数。

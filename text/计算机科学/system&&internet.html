什么是内网穿透(NAT穿透)？
由于家庭网络使用私有ip地址，无法从公网直接访问。内网穿透通过中间服务器在公网和内网之间建立“隧道”转发流量。

什么是私有ip和公网ip？

公网ip由互联网服务提供商（电信、联通、移动..）分配，可以被互联网上的任何设备直接访问，每个公网ip在全球中是唯一的。 由于ipv4稀少，所以不是每个人都有公网ip。

私有ip仅在局域网（LAN）中有效，不能直接访问互联网，需要经过路由器进行网络地址转换NAT才能访问， 设备发送请求到路由器，路由器将私有ip映射到公网ip来请求公网服务器并转发到对应设备。 私有ip在局域网内唯一。

什么是局域网（LAN）？就是一定区域内连接多台设备的私有网络。

什么是子网掩码？子网掩码决定了私有ip的规模以及判断两个设备是否处于同一个子网。子网掩码也用CIDR表示法来表示，例如192.168.1.1/24，后边的数字表示1的数量。 对于接入很多设备的网络来说，可以通过子网掩码来分割网络。例如掩码为/25（255.255.255.128），那么ip在0-127和128-255各自在一个子网中。

什么是网关？网关就是局域网访问公网或者不同子网的出口。网关必须与设备在同一个子网。局域网所有设备共享一个网关ip。

一个路由器有一个WAN接口接到公网，通常四个LAN接口，还有无限接口。四个LAN接口意味着可以有限连接四台设备，这四台设备共享一个网关IP，每个设备的ip不同。

什么是DNS：DNS负责把域名转化为对应的公网ip。
所以DNS污染就是把域名指定到错误的公网ip，这时候只要直接访问ip即可。
用ping example.com查询，但是可能被区域节点CDN影响。
用nslookup example.com查询ip，

或者用Resolve-DnsName example.com。
不过这种方式有时候会遇到cloudflare的direct ip access not allowed制裁。

既然SNI会审查返回的域名，那么在发送请求的时候要求服务器不返回该域名不就好了吗？ 然而，一个ip地址可能托管了数百个网站，服务器需要知道用户想要访问哪个网站，才能返回正确的网站。因此，https要求证书匹配相同。

访问某个域名会依次发生：
1. DNS解析域名为IP：优先级依次是浏览器缓存->hosts->DNS缓存->ISP的DNS服务器->..权威服务器
2. TCP三次握手：

  • 客户端发送SYN
  • 服务器恢复SYN+ACK
  • 客户端发送ACK

    • 3. TLS握手（仅在https下发生）：
  • ClientHallo
  • ServerHallo

    • 4. 发送http请求
    5. 接受http响应
    ...

    主流代理方式有HTTP、SOCKS5、VPN。
